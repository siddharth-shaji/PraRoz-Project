**PraRoz – Web Design & Development Course Website**

A modern educational landing page designed to promote a web design and development course. 
It features a navigation menu, an introduction to web development, and a call-to-action button for hiring or exploring services. 
The page also includes a login form where users can enter their email and password, sign up for an account, and access social media login options. 
The design combines course information with a user authentication interface.
